# ステータス表示テキストの変更

## 依頼内容
> API リクストの完了待ちを待機中ではなく準備中、再生待ちのものを準備中ではなく再生待ちに変えてください。

## 問題点
- ステータス表示が分かりにくかった
  - `STATUS_START`: "待機中"（実際はAPIリクエスト中）
  - `STATUS_PUSHED`: "準備中"（実際は再生待ち）

## 実装内容

### 変更ファイル
- `openai_tts_realtime.html`

### 修正内容

**updateStatusDisplay関数の修正**
```javascript
function updateStatusDisplay() {
  // ...
  const statusText = ["準備中", "再生待ち", "完了"][status[i]] || "不明";
  // ...
}
```

### ステータスの意味

| 定数 | 値 | 表示テキスト | 意味 |
|------|-----|------------|------|
| `STATUS_START` | 0 | **準備中** | APIリクエスト送信中、データ受信待ち |
| `STATUS_PUSHED` | 1 | **再生待ち** | データ受信完了、再生待機中 |
| `STATUS_END` | 2 | **完了** | 再生完了 |

## 結果
- 状態の区別が明確になった
- "準備中": APIリクエスト完了待ち
- "再生待ち": APIリクエスト完了、再生待ち中
- "完了": 再生完了
